# Sunnyside Agency Landing Page

This is a landing page project for Sunnyside Agency. It is built using HTML, CSS, and JavaScript, with Tailwind CSS for styling.

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

- Node.js (https://nodejs.org/)
- npm (Node Package Manager, comes with Node.js)

### Installation

1. Download the project as a zip file and extract it.

2. Navigate to the project directory:

   ```sh
   cd sunnyside-agency
   ```

3. Install the dependencies:

   ```sh
   npm install
   ```

### Usage

1. To start the development server and watch for changes:

   ```sh
   npx tailwindcss -i ./src/input.css -o ./output.css --watch
   ```

2. Open index.html in your browser to view the landing page.
